# Unghie Mamma 💅

Agenda semplice, veloce e pensata per mobile per la gestione di appuntamenti, schede clienti e incassi per ricostruzione unghie.

## 🌐 Sito Online in Produzione
L'app è ospitata ed effettivamente utilizzata all'indirizzo:
👉 **[https://lallievi-cell.github.io/](https://lallievi-cell.github.io/)**

## 📱 Utilizzo su iPhone
- L'app è installata sulla schermata Home dell'iPhone di mamma.
- I dati risiedono nella memoria locale del dispositivo (`localStorage`).
- Prima di qualsiasi modifica o spostamento, consultare sempre il file [`AGENTS.md`](./AGENTS.md).

## 🛡️ Backup e Ripristino
Dalla sezione **Soldi** (💶) dell'app è possibile esportare in qualsiasi momento una copia completa di sicurezza (`Salva copia`) e ripristinarla in caso di necessità (`Ripristina`).
